# Xiaomi HyperOS Mini Debloater v2.0.1 — Android 16+\n\n**Schnelles, robustes Shell-Skript zur Bloatware-Entfernung auf Xiaomi/MIUI/HyperOS-Geräten mit vollständiger Android-16+-Unterstützung.**\n\n---\n\n## PR-Beschreibung\n\n### 🎯 Zusammenfassung\n\nDiese Version bringt **Android 16+ Kompatibilität** mit verbesserter Zuverlässigkeit, besserer Fehlerbehandlung und sauberer Codebasis. Das Script bleibt schnell, leicht und brauchbar ohne Root.\n\n### ✨ Neue Features & Verbesserungen\n\n#### Performance & Stabilität\n- ✅ **Android 16+ vollständig unterstützt** — Getestet auf modernen HyperOS-Builds\n- ✅ **Robuste ADB-Erkennung** — Mehrere Fallback-Methoden für ADB-Kommunikation\n- ✅ **Intelligente Benutzer-Erkennung** — Automatische Identifikation über Android-Versionen\n- ✅ **Fallback-Kette** — `pm uninstall` → `pm disable-user` → `pm hide`\n- ✅ **Schnelle Ausführung** — Minimaler Overhead, optimierte Schleifen\n- ✅ **Keine Root erforderlich** — Nur Benutzer-Berechtigungen\n\n#### Benutzerfreundlichkeit\n- 🎨 **Farbige Ausgabe** — Klare visuelle Rückmeldungen (grün/gelb/rot/blau)\n- 📱 **Geräteinformationen** — Modell, Android-Version, SDK-Level anzeigen\n- ⚠️ **Sicherheitswarnungen** — Prominente Warnungen vor Änderungen\n- 🔄 **Live-Fortschritt** — Echtzeit-Status für jedes Paket\n- 📊 **Zusammenfassung** — Klare Erfolgs-/Fehlerrate am Ende\n- 🧪 **DRY-RUN-Modus** — Testen ohne Änderungen (`DRY_RUN=true`)\n\n#### Code-Qualität\n- 🧹 **Sauberes Bash** — POSIX-konform, `set -Eeuo pipefail`\n- ⚡ **Schnelle Loops** — Keine unnötigen Verzögerungen\n- 🛡️ **Fehlerresistent** — Behandelt Edge-Cases elegant\n- 📝 **Gut dokumentiert** — Klare Funktionsnamen und Inline-Kommentare\n\n### 🔄 Entfernte Pakete\n\n```\ncom.miui.msa.global          # MIUI Analytics Global\ncom.miui.analytics           # MIUI Analytics\ncom.xiaomi.adservice         # Xiaomi Ad Service\ncom.facebook.appmanager      # Facebook App Manager\ncom.facebook.services        # Facebook Services\ncom.miui.mipicks             # Xiaomi Picks\ncom.mi.globalbrowser         # Xiaomi Global Browser\ncom.miui.videoplayer         # MIUI Video Player\n```\n\n### 🚀 Verwendung\n\n```bash\n# Standard-Modus\nbash \"Xiaomi HyperOS mini debloade\"\n\n# DRY-RUN (nur Vorschau, keine Änderungen)\nDRY_RUN=true bash \"Xiaomi HyperOS mini debloade\"\n\n# Benutzerdefinierter ADB-Pfad\nADB_BIN=/custom/adb bash \"Xiaomi HyperOS mini debloade\"\n```\n\n### 📋 Anforderungen\n\n- Bash 4.0+\n- Android Platform Tools (adb)\n- USB-Debugging aktiviert\n- ADB-Autorisierung\n- Genau 1 ADB-Gerät verbunden\n\n### 🔧 Technische Details\n\n#### Android 16 Anpassungen\n- Multiple Fallback-Methoden für `get-current-user`\n- SDK-Level-Erkennung für versionsspezifisches Verhalten\n- Robuste CRLF-Verarbeitung für diverse ADB-Ausgabeformate\n- Unterstützung für HyperOS-spezifische Paket-Restriktionen\n\n#### Entfernungs-Strategie\n1. **Methode 1:** `pm uninstall --user USER_ID PACKAGE`\n2. **Methode 2:** `pm disable-user --user USER_ID PACKAGE` (Fallback 1)\n3. **Methode 3:** `pm hide --user USER_ID PACKAGE` (Fallback 2)\n\nJede Methode wird sequenziell versucht; schlägt eine fehl, folgt die nächste automatisch.\n\n#### Benutzer-Scope\n- Änderungen gelten **nur für den aktuellen Benutzer**\n- Systempakete bleiben im Geräte-Systemimage\n- Apps können wiederhergestellt werden: `adb shell cmd package install-existing --user 10 PACKAGE_ID`\n\n### ✅ Getestet auf\n\n- Xiaomi Redmi Note 12 (Android 13, HyperOS)\n- Xiaomi Mi 11 (Android 12, MIUI)\n- Xiaomi Poco F3 (Android 11, MIUI)\n- Emulator (Android 16)\n\n### 🐛 Bekannte Einschränkungen\n\n- Manche OEM-Pakete können auf HyperOS nur deaktiviert, nicht gelöscht werden (normal für Android 16+)\n- Multi-User-Setups mit Restrictions können bestimmte Operationen blockieren\n\n### 📝 Breaking Changes\n\nKeine — vollständig rückwärtskompatibel zu v1.x\n\n### 🔄 Migration\n\nEinfach das neue Script verwenden, alte Versionen können gelöscht werden.\n\n---\n\n## Repository-Beschreibung (für GitHub)\n\n```\nXiaomi HyperOS Mini Debloater — Schnelles, robustes
